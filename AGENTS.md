# AGENTS.md

## Purpose
Maintain this site as a distinctive Traditional Chinese technology essay, not a generic AI-generated landing page.

## Editorial voice
- Write with a clear point of view. Explain why a detail matters instead of listing features.
- Prefer concrete observations, specific examples, and varied sentence length.
- Avoid inflated claims, repetitive summaries, canned transitions, excessive headings, and symmetrical three-item lists.
- Do not imitate a named living author.
- Keep technical names consistent: `.NET 10`, `C#`, `File-based Apps`, `.csproj`, `NuGet`, `AI Agent`.
- Use Traditional Chinese used in Taiwan.

## Visual direction
- Treat the page as a long-form author essay, not a SaaS landing page.
- Keep the paper, ink, dark red, and editorial typography system coherent.
- Avoid purple gradients, glassmorphism, floating pill badges, emoji icons, excessive rounded cards, and repetitive three-card grids.
- Use alignment, whitespace, typography, and rules before shadows or decoration.
- Code is supporting evidence, not the dominant visual identity.

## Interface quality
- Follow Vercel Web Interface Guidelines where applicable.
- Preserve keyboard access, visible focus states, semantic headings, skip navigation, 44 px mobile hit targets, safe-area support, and responsive behavior.
- Test narrow mobile, laptop, and wide desktop layouts.
- Use native HTML semantics before ARIA.

## Code examples
- Use Prism syntax highlighting with language-specific classes.
- Keep examples correct, short, and copyable.
- Mark technical identifiers with `<code>` and keep code blocks readable on mobile.

## Discovery
Keep these files current when content changes:
- `llms.txt`
- `sitemap.xml`
- `sitemap.md`
- `article.md`
- Open Graph and JSON-LD metadata in `index.html`
