⚡ .NET 10 · File-based Apps

C# 現在也能像 Python 腳本一樣，存成一個檔案就跑

不用先建立 .csproj，直接寫一個 .cs 檔並執行。很適合 AI Agent 工具、一次性資料處理、自動化與快速原型。

立即看 Demo為什麼適合 AI
30 秒上手

第一個單檔 C# 程式

1. 建立 hello.cs

hello.cs
var name = args.Length > 0 ? args[0] : "World";
Console.WriteLine($"Hello, {name}!");

2. 直接執行

Terminal
dotnet hello.cs -- Yazelin

輸出：Hello, Yazelin!

重點：外觀看起來像腳本，但底層仍是正常編譯的 C# 應用程式；SDK 會自動處理暫存專案、建置與快取。
Python
python hello.py

直覺、快速、單檔執行。

.NET 10
dotnet hello.cs

相似的使用體驗，加上 C# 強型別與 .NET 生態。

成長路徑
單檔 → 正式專案

原型變大後，可轉成一般專案繼續維護。

不用 csproj

直接引用 NuGet 套件

在檔案頂端加入 #:package，SDK 會自動還原套件。

console-demo.cs
#:package Spectre.Console@*

using Spectre.Console;

var name = args.FirstOrDefault() ?? "開發者";
AnsiConsole.MarkupLine($"[bold deepskyblue1]Hello, {name}![/]");
Terminal
dotnet console-demo.cs -- Yazelin

#:package#:sdk#:project#:property#:include（SDK 版本有限制）

Web API

一個檔案啟動網站

api.cs
#:sdk Microsoft.NET.Sdk.Web

var app = WebApplication.Create(args);

app.MapGet("/", () => new {
    message = "Hello from a single C# file!",
    runtime = Environment.Version.ToString()
});

app.Run();
Terminal
dotnet api.cs
Unix / macOS / Linux

像真正腳本直接執行

tool.cs
#!/usr/bin/env -S dotnet --

Console.WriteLine($"收到 {args.Length} 個參數");
Terminal
chmod +x tool.cs
./tool.cs one two three
注意：shebang 直接執行僅適用 Unix 類平台；Windows 請使用 dotnet tool.cs。
AI + C#

為什麼 AI Agent 值得考慮 C# 單檔工具？

✓ 容易生成

單一檔案、頂層陳述式，減少樣板與專案結構負擔。

✓ 編譯期檢查

型別錯誤通常能在執行前被發現，降低生成程式碼的低級錯誤。

✓ 企業整合

可直接使用既有 .NET 類別庫、Azure、Windows 與內部 API。

✓ CLI 與 API

適合 JSON、CSV、HTTP、自動化、資料轉換與 Agent tools。

✓ 可升級

概念驗證成功後，可轉成專案型應用，延續原本程式碼。

✓ 可發佈

不只執行，也能建置與發佈成可部署的 .NET 應用程式。

適合：企業自動化、Agent 外部工具、REST API 整合、CLI、小型服務。
Python 仍較強：Notebook、NumPy／Pandas、PyTorch 與資料科學套件生態。
