使用方式

三步完成

安裝 .NET 10 SDK

確認 dotnet --version 顯示 10.x。

建立 .cs 檔案

可直接使用頂層陳述式。

執行

dotnet app.cs 或 dotnet run app.cs。

實用範例

不只是 Hello World

命令列參數

接收 args

var name = args.Length > 0 ? args[0] : "World";
Console.WriteLine($"Hello, {name}!");
NuGet

直接引用套件

#:package Spectre.Console@*
using Spectre.Console;
AnsiConsole.MarkupLine("[green]Ready![/]");
Web API

單檔 Minimal API

#:sdk Microsoft.NET.Sdk.Web
var app = WebApplication.Create(args);
app.MapGet("/", () => "Hello API");
app.Run();

AI / 自動化

為什麼值得 AI Agent 使用？

  • 單檔生成與執行，降低專案樣板成本
  • 強型別與編譯檢查，較容易發現生成錯誤
  • 可直接重用既有 .NET 類別庫
  • 適合 JSON、CSV、HTTP API 與企業系統整合
  • 腳本成熟後可自然升級成正式專案

它不是傳統 .csx

官方名稱是 File-based Apps。使用體驗像腳本，但底層仍是完整編譯的 .NET 應用程式。

Python 仍在 Notebook、資料科學與 PyTorch 生態更成熟；C# 特別適合企業自動化、API 整合與既有 .NET 環境。
